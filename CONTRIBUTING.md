# Contributing

1. Check [open issues](../../issues) - select milestones, pick one issue from milestones, or open a new one to discuss your idea first.
2. Fork, branch, make your change.
3. Please add a test if you're touching logic in `domain` or a Presenter.
4. Open a PR and link the issue it addresses.

Questions? Open an issue and ask - no question is too small.
